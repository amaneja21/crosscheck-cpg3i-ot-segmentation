# Change note — Filtration contractor HMI

A second HMI (10.13.0.13) was added to the Filtration VLAN for a contractor
crew during the summer maintenance window. It was placed on the existing
segment rather than a dedicated one to avoid the cost of an additional
managed switch port and firewall rule set for what was expected to be a
temporary device. No hazardous-area, safety, or technical constraint
prevented placing it on its own segment; this was a budget and scheduling
decision. The device remained in place after the contractor left.

Filed by: Site IT coordinator.
